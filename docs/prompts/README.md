# Reusable prompts

Paste these into the builder agent (or the reviewer model) with the task file attached. They encode the loop in `AGENTS.md`.

- [plan.md](plan.md): get a small plan, no code
- [implement-with-tests.md](implement-with-tests.md): tests first, then code until checks pass
- [review.md](review.md): second-model review for bugs and security
- [explain-this-file.md](explain-this-file.md): learn the code before you merge it
